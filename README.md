# ParkEase – Smart Parking Management
React + Vite + React Router. Data lives in LocalStorage and is mirrored to IndexedDB (auto-restored if LocalStorage is cleared).

1. Install Node.js LTS
2. `npm install`
3. `npm run dev`  then open http://localhost:5173
